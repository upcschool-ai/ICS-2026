# ICS - MLOps 2026

Repository with all the code for the MLOps module of ICS 2026.

## Sessions

- [Session 1](session-1/README.md): minimal PyTorch project (custom dataset, model and training loop).
- [Session 2](session-2/README.md): Train your own model with a custom dataset.
- [Session 3](session-3/README.md): Train a model remotely on a Google Cloud VM over SSH.

## Troubleshooting

If you have issues with installing dependencies in your computer, you can always open this repository from Ona by clicking this button:

[![Open in Ona](https://gitpod.io/button/open-in-gitpod.svg)](https://gitpod.io/#https://github.com/upcschool-ai/ICS-2026/)

You'll have to log onto Ona, which you can do using your Github account (clicking on Login with Github).

This will open a fully functional VSCode in your browser, in which you have full control and you can install any dependencies you need.
